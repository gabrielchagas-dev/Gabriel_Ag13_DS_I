# Meu Portal de Entretenimento Digital

Aluno: Gabriel das Chagas Silva. Agenda 13 de Desenvolvimento de Sistemas I.

Extraia o ZIP inteiro e abra portal.html. Mantenha os arquivos CSS e a pasta
imagens junto do HTML. A página abre sem internet.

## Requisitos implementados
- Três seções temáticas com duas imagens e textos em cada uma.
- CSS inline, interno e externo.
- Reset baseado em Eric Meyer carregado antes de estilo.css.
- Classes para títulos e créditos das imagens e IDs para as seções.
- Flexbox com três colunas em telas largas e adaptação para celular.
- Comentários no HTML e no CSS.
- Registro textual da orientação real de IA e capturas do projeto.

As ilustrações SVG foram criadas por código com auxílio de IA.
O registro não é uma transcrição de etapas realizadas individualmente pelo aluno.
O modelo de documento da escola não foi fornecido; o registro usa formato próprio.
